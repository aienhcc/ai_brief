# AI 브리핑

비개발자 눈높이로 정리하는 주간 AI 코딩 도구 브리핑.
매주 월요일 오전 9시(한국시간)에 클라우드에서 자동 실행되어, 새 호를 이 저장소에 커밋하고
3줄 요약을 카카오톡으로 보냅니다.

읽는 곳 → **https://aienhcc.github.io/ai_brief/**

## 이 저장소에 뭐가 있나

| 파일 | 뭐냐 | 누가 고치나 |
|---|---|---|
| `index.html` | 목록 페이지 (표지) | 자동 (매주 한 줄 추가됨) |
| `ai-brief/YYYY-MM-DD.html` | 각 호 리포트 | 자동 (매주 새 파일 생성) |
| `ai-foundations.html` | 기초 총론 — 용어·연표 | 갱신하지 않음 |
| `brief-instructions.md` | **자동 실행 지시서** | 사람이 고침 |

## 브리핑 형식을 바꾸고 싶으면

`brief-instructions.md` **한 파일만** 고치고 커밋하면 다음 주부터 반영됩니다.
예를 들어 "항목을 3개로 줄여라", "출처를 더 엄격하게 요구해라" 같은 걸 그 파일에 쓰면 됩니다.

## 자동 실행을 끄거나 시간을 바꾸려면

https://claude.ai/code/routines 에서 루틴을 켜고 끌 수 있습니다.

## 수동으로 한 호 만들려면

로컬에서 Claude Code를 열고 `/ai-brief` 를 실행하면 됩니다.
(로컬 커맨드는 `~/.claude/commands/ai-brief.md`에 있고, 자동 실행분과는 별개 사본입니다.)
