AI 브리핑 · 2호 · 2026.08.24 · 지난 한 주

도구가 아니라
‘쓰는 법’이 정리된 주

한 줄 요약

새 모델도, 화제의 신기능도 없었습니다. 대신 말 짧게 시키는 스위치가 생겼고, 무료 공식 강의 사이트가 열렸고, 이 브리핑을 매주 자동으로 받는 방법이 확인됐습니다. 셋 다 “새로 배울 것”이 아니라 “이미 쓰는 걸 덜 피곤하게 쓰는 것”입니다.

이번 주에 딱 하나만

답변을 짧게 바꾸세요. 30초짜리입니다. Claude Code 대화창에 /config → Output style → Concise. 서론과 중계방송이 사라지고 결과부터 나옵니다. 일은 똑같이 꼼꼼하게 합니다.

지금 바로

“Concise” — AI가 말을 줄이게 하는 공식 스위치

이게 뭐냐

말 많은 직원에게 “결론부터 말해”라고 한 번 정해두는 것과 같습니다. 8월 20일 업데이트(버전 2.1.237)로 Claude Code에 출력 스타일(대답하는 말투를 고르는 설정) 중 Concise(간결)가 기본 항목으로 들어왔습니다. “이제 파일을 열어보겠습니다…” 같은 중계방송과 요약 해설을 빼고 결과부터 말합니다.

왜 떴냐

지난 호에서 다룬 “AI가 한 번에 너무 많이 쏟아낸다”와 뿌리가 같습니다. 코드만 많이 나오는 게 아니라 읽어야 할 글도 같이 많아지는데, 그 글의 대부분은 정작 판단에 필요 없는 중계였습니다. 공식 설명에도 “결과를 먼저 내놓고 서론과 나레이션은 생략하되, 일은 똑같이 철저히 한다”고 적혀 있습니다.

나한테 쓸모

코드를 못 읽는 사람일수록 이득이 큽니다. 어차피 안 읽고 넘기던 설명이 줄면, 진짜로 봐야 하는 한 줄(무엇을 바꿨는지, 뭐가 안 됐는지)이 눈에 들어옵니다. 안 맞으면 같은 자리에서 되돌리면 됩니다.

이렇게 켭니다

/config          ← 대화창에 그냥 치세요
  → Output style ← 이 항목을 찾아서
  → Concise      ← 선택하면 끝

※ 되돌리려면 같은 자리에서 Default 선택
지금 바로

이 브리핑, 매주 알아서 만들게 할 수 있습니다 — ‘루틴’

이게 뭐냐

루틴(Routine)은 “매주 월요일 아침에 이 일을 해놔”라고 한 번 걸어두는 예약입니다. 핵심은 이게 내 PC가 아니라 Anthropic 서버에서 돈다는 점입니다. 노트북을 닫아놔도, 꺼놔도 실행됩니다. 총론의 여섯 묶음 중 ‘조직’에 해당합니다 — AI에게 무엇을 시킬지가 아니라 언제 일할지를 정해주는 층입니다.

왜 떴냐

지금까지 “AI에게 반복 작업을 맡긴다”는 말은 실제로는 내가 매번 앉아서 시작 버튼을 누르는 것이었습니다. 지금 이 브리핑도 그렇습니다. 예약 실행이 붙으면서 “내가 여는 순간에만 시작된다”는 제약이 없어졌습니다.

나한테 쓸모

바로 이 주간 브리핑이 1순위 후보입니다. 다만 걸림돌이 하나 있습니다 — 클라우드에서 도는 루틴은 내 PC 폴더에 파일을 저장할 수 없습니다. 그래서 “결과물을 어디로 받을지”를 먼저 정해야 합니다.

알아둘 제약뜻
최소 1시간 간격1분마다·5분마다는 거부됩니다. 주 1회는 문제없음
시간은 UTC 기준한국시간 −9시간. 한국 월요일 오전 9시 = UTC 월요일 0시
내 PC 파일 접근 불가결과는 GitHub 저장소나 카카오톡 ‘나에게 보내기’로 받아야 함

이렇게 물어보세요 (그대로 복사)

매주 월요일 한국시간 오전 9시에 /ai-brief 를 자동으로
실행하는 루틴을 만들어줘.

결과물은 내 PC에 저장하지 말고,
3줄 요약을 카카오톡 "나에게 보내기"로 보내줘.

만들기 전에 어떤 설정으로 걸 건지 3줄로 먼저 알려주고,
내가 동의하면 그때 만들어.

주의 — 루틴은 “걸어두면 알아서 잘 되는 것”이 아닙니다. 초기 몇 주는 결과를 직접 확인하세요. 프롬프트가 조금만 어긋나도 매주 어긋난 결과가 쌓입니다.

나중에

Anthropic이 무료 강의 사이트를 열었습니다 — 비개발자 트랙 있음

이게 뭐냐

8월 20일 Claude Academy(academy.claude.com)가 열렸습니다. 강의 22개, 튜토리얼 119개, 실제 사용 사례 148개. 전부 무료이고 로그인 없이도 읽을 수 있습니다. 로그인하면 진도가 저장되고 수료 배지를 받습니다.

왜 이게 당신한테 맞냐

대부분의 “Claude 강의”는 개발자용인데, 여기엔 비개발자용 트랙이 따로 있습니다. 뼈대가 되는 4D 프레임(위임 Delegation · 서술 Description · 분별 Discernment · 성실 Diligence)은 코딩 얘기가 아니라 “AI에게 뭘 맡기고, 어떻게 설명하고, 결과를 어떻게 의심할지”에 대한 틀입니다. 지난 호에서 “겉보기 멀쩡한 거대한 결과물”을 경계하라고 했던 게 정확히 세 번째 D(분별)입니다.

나한테 쓸모

솔직히 이번 주에 뭐가 만들어지지는 않습니다. 그래서 ‘나중에’입니다. 다만 한 시간 짬이 날 때 열어볼 자료로는 지금 나와 있는 것 중 가장 낫습니다 — 남이 쓴 블로그 글이 아니라 만든 회사가 직접 쓴 것이고, 공짜입니다.

2. AI Fluency: Framework   ← 4D 프레임. 이게 핵심
3. Claude Code 101         ← 지금 쓰는 도구 정리편

academy.claude.com  ← 로그인 없이 먼저 훑어봐도 됩니다
알기만

AI가 화면을 직접 보고 클릭하는 기능이 ‘정식’이 됐습니다

이게 뭐냐

같은 날(8월 20일) Anthropic이 컴퓨터 사용(화면을 보고 마우스·키보드를 직접 움직임)과 브라우저 사용(웹사이트를 직접 돌아다님)을 시험 단계에서 정식으로 올렸습니다. 총론의 ‘행동’ 묶음이 한 칸 넓어진 겁니다 — 지금까지 AI의 손은 파일과 명령어까지였는데, 이제 화면 자체가 손 닿는 범위에 들어왔습니다.

왜 지금은 할 일이 없냐

이건 프로그램을 만드는 사람들이 쓰는 부품으로 풀린 것이지, 당신 화면에 버튼이 생긴 게 아닙니다. 오늘 “대신 예약해줘”라고 시킬 수 있는 건 아닙니다.

그래도 기억해둘 것

‘시험판’과 ‘정식’의 차이는 회사들이 실제 서비스에 넣기 시작한다는 뜻입니다. 몇 달 안에 여러 서비스에서 “대신 사이트 들어가서 처리하고 결과 가져오기”가 평범한 기능으로 등장할 겁니다. 그때 진짜 질문은 “내 계정으로 대신 들어가게 둘 것이냐”가 됩니다 — 총론의 ‘신뢰’ 묶음 문제로 넘어갑니다.
